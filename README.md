# 📌 SAE S3 – Projet Web

## 📄 Présentation

Ce dépôt contient le code source du projet réalisé dans le cadre de la **SAÉ S3** du BUT Informatique.  
Le projet consiste en une **application Web dynamique** (PHP/HTML/CSS/JavaScript) répondant à un cahier des charges défini en début de semestre.

Ce projet respecte les objectifs pédagogiques de la SAÉ :  
- développer une application web complète  
- organiser la navigation, l’authentification et les fonctionnalités côté serveur  
- utiliser un système de gestion de versions collaboratif GitHub
